# Superteam submission checklist

## Deliverable

- [ ] Public GitHub repository with this README and source.
- [ ] Screenshot or terminal transcript of a successful T3N sandbox handshake and authenticated credit-balance read.
- [ ] Screenshot or transcript of the test suite and a redacted example run.
- [ ] Public Google Doc containing the repository link, screenshots, setup notes, and any T3N/SDK issue found.

## Before publishing

- [ ] Confirm no private key, API key, wallet seed phrase, or real customer data appears in Git history, screenshots, source, or documents.
- [ ] Use a separate credited agent key if publishing the T3N agent card.
- [ ] Do not enable external side effects in the agent without an explicit, narrowly scoped delegation.
